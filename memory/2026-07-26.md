## 🔧 2026-07-26 — PNL Discount Fix + Sale Bot Inventory Root Cause (18:06 UTC)

### ✅ PNL Discount Formula Fixed
**Problem:** `SUM(gross - net)` inflated discounts by including deposit redemption (394K Ks) and other items (683K Ks). Real July discount = only 15,950 Ks.
**Fix:** Changed from `SUM(gross - net)` to `SUM(discount)` in `finance_routes.py`:
  - Line 509 (balance endpoint)
  - Line 540 (PNL endpoint)
  - Line 546 (PNL endpoint backup)
**Impact:** Cosmetic only — discount field in PNL output not used for balance/net profit calculations.

### ✅ Sale Bot Inventory — Root Cause Found & Fixed
**Root Cause:** Item names with underscore (`_`) break Telegram Markdown parser. Items affected:
  - `လျှာဂျွမ်းထိုး_ဟော့ဟော့`
  - `Birdy_3 in 1`
  - `Spicy_Sasuge_Stick`
  - `Yum Top_Sasuge`

**Symptom:** "⏳ Inventory စစ်ဆေးနေသည်..." loading message appears, then nothing (no error shown to user). Log shows:
```
[WARNING] Network issue (will auto-retry): Can't parse entities:
  can't find end of the entity starting at byte offset 2037
```

**Fix:** Added markdown escape (`\\_`, `\\*`, `` \\` ``) to item name lines in `cmd_inventory()` — `bot/handlers/reports.py`
**Restart:** Sale bot service restarted ✅

### 📚 New Lessons
| # | Lesson |
|:-:|--------|
| 209 | **Telegram Markdown + underscores in item names** — Underscore is Markdown italic marker. Item names with `_` cause "Can't parse entities" error. Always escape `_`, `*`, `` ` `` in user-facing inventory/item names when using `parse_mode="Markdown"`. If item has no bold markers, safe to blanket-escape the fields. |
