## 🔧 2026-07-26 — Deposit Financial Flow Fixes (Post-Migration)

### ✅ 1. Forfeited Deposit → Account Balance Fix
**Problem:** Forfeited deposits (no-show/cancel) were missing from Account Balance. Anti-double-count code subtracted ALL "Deposit #" injects, but forfeited deposits had no corresponding sales_daily income.

**Fix (booking_routes.py):**
- **Manual Cancel:** Added `deposit_status, deposit_amount, deposit_method` to pre-cancel SELECT + cash_movements `Forfeit BK#` inject after forfeit
- **Auto-Cancel-No-Show:** Added `deposit_method` to pre-check query + cash_movements `Forfeit BK#` inject after forfeit
- **Backfill:** cash_movements rows 550-560 for all historical forfeited entries

### ✅ 2. Active Deposit → Account Balance Fix
**Problem:** Active (paid/verified) deposits also missing from balance — same anti-double-count subtraction issue.

**Fix (finance_routes.py):**
- Added balance adjustment code to add back truly active deposits (deposit_status IN 'paid','verified' AND booking status NOT IN 'cancelled','done')
- Only truly active: BK#2042 (10,800 Ks, confirmed+verified) ✅

### ✅ 3. Deposit Status Cleanup (Business Logic Backfill)
**Boss's ruling:** "Verify မလုပ်ဘဲ cancel" = no money received → just clean up. "Verify ပြီးမှ cancel" = forfeit income.

| Group | Amount | Action |
|:------|:------:|:-------|
| A: paid+cancelled (no verify) | 15,000 Ks | deposit_status→none, amount→0 |
| B: verified+cancelled (money received) | 9,500 Ks | Backfilled as forfeit (rows 557-559) |
| C: done+verified (deposit未redeem) | 7,000 Ks | Backfilled as forfeit (row 560) |

**Final totals:** True Active (10,800) + Forfeited (41,200) + Redeemed (393,400) + Refunded (38,000) + Pending (6,000) = **489,400 Ks all-time**

### ✅ 4. Session Duplicates Fix
**Problem:** Reconciliation showed BK#2044 as "missing sale" — root cause was duplicate session rows for BK#2027.

**Duplicates deleted:** BK#1559 (1304), BK#1627 (1369), BK#1710 (1441), BK#2027 (1705) = 4 rows
